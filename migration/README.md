# Перенесення стрічки новин зі старого сайту (14.10.2026)

Довідкова тека. **На хостинг не викладати.** Сайт, як і раніше, не має збірки:
ці скрипти один раз склали `site-data.json` і блок `const DATA` в `index.html`.

| Файл | Що це |
|---|---|
| `registry.json` | усі блоки старого сайту й знімків Web Archive: текст по рядках, зображення, файли |
| `spec-a.js` | матеріали 2023–2026: які блоки → у який матеріал, фото, протоколи, регламенти |
| `spec-b.js` | матеріали 2020–2022 (переклад з російської за рішенням замовника) |
| `spec-results.js` | вкладки «Результати» й «Чемпіони» розділу «Турніри» |
| `fixes.js` | виправлення наявних транскрипцій після звірки з протоколами |
| `build.js` | збирання: база + специфікації → дані сайту, завантаження фото, перевірки |
| `make-htaccess.js` | генерація `site/.htaccess` |
| `media-manifest.js` | перші 20 перенесених файлів (до масового перенесення) |
| `base-data-before-migration.json` | дані сайту до перенесення (25 матеріалів) |
| `transcribed.js` | 16 підсумкових таблиць, переписаних з фото протоколів і звірених рядок за рядком |
| `players.js`, `players-spec.js` | реєстр шахістів: виступи з підсумкових таблиць, зведення написань, рейтинги FIDE |
| `players-report.txt` | звіт останнього зведення: об'єднані написання, гравці без збігу у FIDE |
| `fide-extract-ukr.js` | витягує гравців UKR зі списку FIDE (`players_list.zip`) у `fide/ukr.json` |
| `ui-players.js` + `.client.js` | патч `index.html`: «Шахісти», «Зала чемпіонів», «Клуб у цифрах» |
| `ui-editor.js` + `.client.js` | патч `index.html`: редактор сайту з публікацією через `publish.php` |
| `ui-design.js` | патч `index.html`: оформлення «Турнірний зал» (стилі, перший екран, плитки без фото) |
| `ui-motion.js` + `.client.js` | патч `index.html`: анімації «шаховий космос» (сцена першого екрана, шапки, поява блоків, переходи, графіки) |
| `ui-hero-photo.js` + `hero-photo.client.js` | патч `index.html`: перший екран зі справжнім фото (Воронцовський маяк, CC BY 3.0) і живими відблисками, чайками |
| `fidecheck/` | звірка з FIDE: `fetch-hist.js` (історія рейтингів з ratings.fide.com), `verify.js` (звірка з протоколами), `search-all.js` (пошук у всіх федераціях), `hist/` (завантажена історія, 14.10.2026), `fide-extra.json` (гравці інших федерацій; містить роки народження — не публікувати) |

Патчі `ui-*.js` уже внесено в `site/index.html`; повторний запуск безпечний
(замінює лише свої блоки). `fide/ukr.json` (3 МБ, містить роки народження) сюди
не скопійовано — його відтворює `fide-extract-ukr.js` зі свіжого списку FIDE.

**Увага:** `build.js` збирає дані наново з `base-data-before-migration.json` і
специфікацій. Після того як клуб почне публікувати з редактора, запуск `build.js`
перезапише їхні публікації — тоді працювати з `site-data.json`, забраним з хостингу.

Посилання на блоки в специфікаціях: `N:16` — сторінка «Новости» (WP id 49), блок 16;
`H` — головна (1870), `T` — «Турніри» (676), `A` — архів новин у Web Archive (знімок 08.09.2024),
`R` — головна в Web Archive (08.08.2022). Тексти цих блоків лежать у
`sources/oldsite-2026-10-14/`.

Шляхи в `build.js` вказують на тимчасову теку, де скрипти виконувались; для повторного
запуску їх треба поправити (`SITE`, шляхи до `registry.json` і `media-sizes.json`).
