# Пакет проєкту «Шахова Одеса»

Передача проєкту в Claude Code. Розпакувати, відкрити теку в Claude Code —
файл `CLAUDE.md` прочитається автоматично.

## Що де лежить

```
CLAUDE.md                 брифінг проєкту — читати першим
README.md                 цей файл

site/                     ГОТОВИЙ САЙТ
  index.html              увесь сайт одним файлом
  site-data.json          контент окремо (резервна копія)
  assets/                 логотип і іконки
  README.txt              інструкція для замовника

spec/                     ТЗ ВІД ЗАМОВНИКА
  tz-1-pershe.md          перша версія (LIVE, складна структура) — скасована
  tz-2-druhe.md           друга версія (світлий дизайн, Supabase) — скасована
  tz-3-chynne.md          ТРЕТЯ, ЧИННА: без LIVE, турніри = лише анонси

sources/                  ПЕРШОДЖЕРЕЛА
  archives/               два docx-витяги зі старого сайту (2023, 2024)
  screenshots/            49 скріншотів chessclub.com.ua — протоколи
                          Swiss-Manager, таблиці, парування, регламенти
  oldsite-2026-10-14/     тексти старого сайту й знімків Web Archive 2020–2026,
                          з яких перенесено стрічку новин

migration/                СКРИПТИ ПЕРЕНЕСЕННЯ (14.10.2026) — лише довідка,
                          на хостинг не викладати
```

## Швидкий старт

1. Відкрити `site/index.html` у браузері — подивитися, що вже зроблено.
2. Прочитати `CLAUDE.md` — стан, архітектура, правила.
3. Прочитати `spec/tz-3-chynne.md` — чинне ТЗ замовника.
4. Перші дві версії ТЗ — лише для розуміння, чому проєкт такий, як є.
   Не виконувати: їхні вимоги замовник скасував.

## Головне правило

Нічого не вигадувати. Ні прізвищ, ні рейтингів, ні дат, ні результатів.
Якщо дані нечіткі — статус «Потребує уточнення».
