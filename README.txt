ШАХОВА ОДЕСА — вебсайт
Об'єднання шахово-шашкових клубів Одеської області

СКЛАД АРХІВУ
  index.html       — увесь сайт: розмітка, стилі, скрипт і контент в одному файлі
  site-data.json   — той самий контент окремим файлом (резервна копія для редагування)
  assets/          — логотип та іконки

ЯК ПОДИВИТИСЯ ЗАРАЗ
  Розпакуйте архів і відкрийте index.html подвійним кліком.
  Працює у Chrome, Edge, Firefox, Safari — на комп'ютері, планшеті й телефоні.
  Інтернет потрібен лише для шрифтів; без нього сайт відкриється системним шрифтом.

ЯК ВИКЛАСТИ В МЕРЕЖУ
  Скопіюйте index.html і теку assets у кореневу теку хостингу.
  Жодних баз даних, PHP чи налаштувань сервера не потрібно.
  Для домену chessclub.com.ua — просто замініть уміст кореневої теки.

ЯК РЕДАГУВАТИ КОНТЕНТ
  1. Відкрийте сайт і перейдіть за адресою index.html#/editor
  2. Код доступу: odesa
  3. Додайте або змініть новину чи анонс
  4. Натисніть «Зберегти site-data.json» — файл завантажиться в теку «Завантаження»
  5. Замініть ним site-data.json в архіві
  6. Щоб зміни потрапили на сайт, відкрийте index.html у текстовому редакторі,
     знайдіть рядок «const DATA = {» і замініть увесь об'єкт вмістом нового site-data.json

  Код доступу змінюється в index.html: знайдіть 'odesa' у функції bind.
